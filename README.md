# หลักสูตร Ruby on Rails: จากศูนย์สู่ระดับโลก (Step 1–1000)

หลักสูตรนี้พาผู้เรียนเดินทางตั้งแต่ **ไม่มีพื้นฐานเขียนโปรแกรมเลย** ไปจนถึงระดับที่สามารถ
ออกแบบสถาปัตยกรรมระบบขนาดใหญ่, ทำงานร่วมกับทีมระดับ Staff/Principal Engineer,
และส่งงานที่พร้อมใช้งานจริงในระดับ production ระดับโลกด้วย Ruby on Rails

หลักสูตรแบ่งเป็น **100+ Part** ครอบคลุม **1000 Step** โดยแต่ละ Part จะมีเนื้อหาที่ใช้งานได้จริง
100% (โค้ดรันได้จริง มีคำอธิบายทีละบรรทัดในจุดที่สำคัญ, แบบฝึกหัด, และ checklist)

> โครงสร้างนี้เขียนและเรียบเรียงต่อเนื่องไปเรื่อยๆ — ดูสถานะความคืบหน้าได้ที่
> [`course/00-outline.md`](course/00-outline.md) หัวข้อ "สถานะความคืบหน้า"

## วิธีใช้หลักสูตรนี้

1. เริ่มจาก [`course/00-outline.md`](course/00-outline.md) เพื่อดูภาพรวมทั้งหมด
2. เรียนตามลำดับ Part 1 → Part 100+ (แต่ละ Part อยู่ในโฟลเดอร์ตามเฟส เช่น `course/01-fundamentals/part-001-*.md`)
3. ทำแบบฝึกหัดท้ายบทก่อนไป Part ถัดไปเสมอ
4. โค้ดตัวอย่างทั้งหมดทดสอบบน **Ruby 3.3+ / Rails 7.1+** (จะระบุเวอร์ชันเฉพาะเจาะจงเมื่อจำเป็น)
